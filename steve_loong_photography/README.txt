STEVE LOONG PHOTOGRAPHY — QUICK START

1. Open index.html to preview the site.
2. Put your photographs in the images folder.
3. In index.html, replace a placeholder such as:
   <div class="photo placeholder"><span>YOUR PHOTO 01</span></div>
   with:
   <div class="photo"><img src="images/photo01.jpg" alt="Description"></div>
4. Add this CSS if using images:
   .photo img { width:100%; height:100%; object-fit:cover; }
